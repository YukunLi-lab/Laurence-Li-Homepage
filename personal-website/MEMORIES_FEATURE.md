# "我的珍贵回忆"功能文档

## 🌟 功能概述

"我的珍贵回忆"是一个沉浸式、怀旧且极其纯粹的视觉空间，为用户提供一个无文字、无评论、无点赞的纯粹视觉体验。用户进入这个板块时，背景噪音消失，只剩下流淌的画面。

## 🎨 视觉与交互设计

### 氛围感 (Atmosphere)
- **低饱和度背景**: 采用深色渐变背景，营造怀旧氛围
- **磨砂玻璃效果**: 使用CSS `backdrop-filter: blur()` 实现Glassmorphism效果
- **浮动元素**: 背景包含微妙的径向渐变，增强深度感

### 布局 (Layout)
- **非对称瀑布流**: 采用Masonry布局，打破死板的方块排列
- **响应式网格**: 自适应不同屏幕尺寸（桌面3列，平板2列，手机1列）
- **粘性侧边栏**: 年份筛选和上传区域固定在侧边

### 动效 (Motion)
- **呼吸感转场**: 所有转场都带有缓动效果，使用 `cubic-bezier(0.4, 0, 0.2, 1)`
- **悬停放大**: 照片/视频悬停时轻微放大（scale: 1.05）
- **视频自动预览**: 视频在视口中自动静音循环播放

## 🛠️ 核心功能

### 1. 上传功能
- **支持格式**: JPG, PNG, MP4, MOV
- **上传方式**: 
  - 拖拽上传（支持多文件）
  - 点击上传区域选择文件
  - 点击"浏览文件"按钮
- **文件验证**: 客户端验证文件类型
- **上传反馈**: 实时通知系统显示上传状态

### 2. 展示功能
- **瀑布流布局**: 自动排列不同尺寸的媒体
- **年份筛选**: 按年份过滤回忆（2021-2024 + 全部）
- **沉浸式画廊**: 点击后全屏查看，背景深度模糊
- **日期显示**: 自动从EXIF读取或使用文件修改日期，微弱显示在角落

### 3. 媒体处理
- **智能适配**: 视频封面自动裁剪为4:5或1:1比例
- **视口触发**: 视频在进入视口时自动播放，离开时暂停
- **懒加载**: 图片使用 `loading="lazy"` 属性
- **响应式图片**: 根据屏幕尺寸加载合适大小的图片

### 4. 时间轴驱动
- **默认排序**: 按拍摄时间倒序排列
- **年份侧边栏**: 仅显示年份，保持界面极度干净
- **无文字设计**: 不给每张照片加标题，保持纯粹视觉体验

## 🔧 使用方法

### 1. 添加新回忆
1. 拖拽文件到上传区域，或点击"浏览文件"
2. 选择JPG、PNG、MP4或MOV文件
3. 等待上传完成，新回忆会自动添加到网格

### 2. 浏览回忆
1. 使用年份筛选按钮过滤内容
2. 点击任何回忆打开全屏查看器
3. 在全屏模式下使用左右箭头键导航

### 3. 键盘快捷键
- **ESC**: 关闭全屏查看器
- **← →**: 在全屏模式下切换回忆
- **点击**: 打开/关闭全屏查看器
